## How to use it

1. Upload any task-related file (drawings, reports, spreadsheets, etc.) to the SharePoint folder above.
2. In the task file you are assigned to, add a link to that SharePoint file so everyone can read it:

   - [Link name](<SharePoint URL>)

Do not store copies of files inside this vault — keep the single source of truth on SharePoint and link to it from the tasks.
